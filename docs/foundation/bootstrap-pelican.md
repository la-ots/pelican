## Bootstrap & Pelican 2

Bootstrap is a <strong>frontend framework</strong>. Pelican 2 is a <strong>design system</strong>. 

Frontend frameworks handle things like responsiveness, CSS, and HTML construction, while design systems act as the overarching source of truth for visual identity, guidelines, and user experience consistency. They don’t compete but they are highly complementary pieces of modern product production.

Pelican 2 is based on Bootstrap and specifically uses <a href="https://getbootstrap.com/docs/5.3/getting-started/introduction/">Bootstrap 5.3.3</a>. Some of the Components in Pelican 2 are directly taken from Bootstrap. Other components are custom for Pelican 2 but they’re built on what Bootstrap provides.
